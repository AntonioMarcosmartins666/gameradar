# 🎮 GameRadar

## 🕹️ Plataforma para encontrar jogos para PC

O **GameRadar** é uma aplicação web desenvolvida para ajudar jogadores a encontrar jogos para PC, comparar preços e descobrir oportunidades de compra.

A plataforma reúne informações sobre **ofertas, jogos gratuitos e histórico de preços**, proporcionando uma experiência simples e objetiva para pesquisar jogos.

---

## 🎯 Objetivo do projeto

O **GameRadar** foi desenvolvido com o objetivo de facilitar a descoberta de jogos e ajudar o usuário a encontrar oportunidades de compra.

A proposta é centralizar informações relevantes sobre **jogos, preços, ofertas e histórico de valores** em uma interface simples e fácil de navegar.
